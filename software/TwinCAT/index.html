    软件环境

    网页中的说明基于TwinCAT 3.1 4026环境，功能安全产品的使用上与 TwinCAT 3.1.4024 版本基本没有差异，使用的安全编辑器版本为1.4.15。

    TwinCAT 3.1 4024 环境

    自TwinCAT 3.1.4024.11 版本起，TE9000 | TwinCAT 3 Safety Editor可以作为独立的组件进行更新。 安装TwinCAT 3.1.4024 时会自动安装 TE9000 安全编辑器，自动安装的 TE9000 版本可能会较低，需要自行进行更新。 可以在电脑的控制面板安装与卸载查看当前的 TE9000 版本，如需下载最新的 TE9000 软件，请访问 倍福TwinSAFE官网。

    TwinCAT 3.1 4026 环境

    TwinCAT 3.1 4026 环境中，通过 TwinCAT Package Manager 软件可更新各功能组件，包括TE9000。

    注意

    使用不同版本的 TE9000 版本创建的安全项目存在兼容性问题。低版本无法打开高版本的项目；高版本打开低版本项目时会提示需要升级工程内的安全项目，旧的安全项目会在工程文件夹内进行备份。 协同工作时，请确保统一的工程环境。
